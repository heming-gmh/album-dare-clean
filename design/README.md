# 设计稿

## hifi-prototype.html

六屏高保真原型，单文件，双击打开，不需要 DevEco，也不需要设计工具。

- 顶部 `1–6` 切屏；屏内可点：确认家人、勾选建议移出、进回收站、恢复。
- 右侧是每一屏的设计说明：这一屏做什么、验证什么、红线是什么。
- 「全部铺开」按设计评审的样子摊开六屏。

对着的原型需求见 `docs/PRD.md`，方向取舍见 `docs/PRODUCT-DIRECTIONS.md`。

## 约定

- 原型里的数据全部是假的，但**规则是真的**：三桶的判定沿用 `packages/core` 的闸门语义
  （没建档的人不产生移出建议、未识别的脸进不确定、建议不会自动执行）。
- 文案红线沿用 `docs/AC.md` AC-7：用「智能整理」「分组建议」「建议移出图库」，
  不用「强力清理」，不把照片叫垃圾，不承诺没算过的空间数字。
- 命名（`album dare clean`）是占位，未定。
