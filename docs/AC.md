# 验收摘要

体验版要在大约一刻钟里让人看懂三桶，而不是扫完整库。

| 编号 | 摘要 | 现在落在哪 |
| --- | --- | --- |
| AC-1 | 能留下 2 到 3 位家人，每人至少 3 张样例。演示模式用内置样例，不挑真实照片。 | 鸿蒙建档页；core 的 `MIN_PROTOTYPES` |
| AC-2 | 轨 A：模板句或人物卡片，合并成 PolicyAST v0.3。 | `compileIntent` |
| AC-3 | 意图里有没建档完成的人时，不得产生可执行的 `delete_cand`。 | `executableDelete === false` 时闸门只给 keep 或 uncertain |
| AC-4 | 先处理一小撮，马上分成三桶。不确定桶单独呈现，不能并进可删候选。 | `classifyAll`；结果页琥珀色不确定区，且没有勾选框 |
| AC-5 | 可删视频有关键帧条，并写明为什么建议移出。 | 样例视频带关键帧；原因里写覆盖和关键帧数 |
| AC-6 | 勾选后进入应用回收站，可以恢复，持有至少 30 天，没有午夜自动删除。 | `hold` / `restore`；回收站页 |
| AC-7 | 文案用「智能整理」「分组建议」「建议移出图库」。不用「强力清理」，也不把内容叫作垃圾。 | 页面文案；`npm test` 会扫 `.ets` |
| AC-8 | 不上传原片；不做相似图或最佳照片；媒体库和视觉只是适配层。 | `fixture://` 指针；设备适配返回空或不确定 |

演示前，盲测里的 T1 和 T3 必须通过。逻辑部分由 `packages/core` 的单测覆盖。真机上再按 `docs/BLIND_TEST.md` 点一遍。
